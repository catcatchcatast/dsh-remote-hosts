# Security policy

## Supported versions

| Version | Security reports accepted |
| --- | --- |
| DSH 0.1.2 Preview (`0.1.2-rc.1`) | Yes |
| DSH 0.1.5 | Not supported; adaptation is in progress |

Please use GitHub private vulnerability reporting when available, or email
`catcatchcatast@gmail.com`. Do not open a public issue containing tokens, keys,
authorization URLs, real IP addresses, hostnames, device serial numbers,
session content, or private logs.

Include the affected package/version, impact, minimal reproduction, and a
redacted diagnostic sample. You will receive an acknowledgement when the
report can be reviewed; no disclosure or fix timeline is promised.
