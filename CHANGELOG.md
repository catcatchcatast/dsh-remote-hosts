# Changelog

## 0.1.2 Preview

- Published the compatibility plugin sources for DeepSeek Harness
  `0.1.2-rc.1`.
- Added multi-host routing, shared browser streams, Android compatibility
  endpoints, directory selection, subscription compatibility, and model/menu
  compatibility packages without modifying `dsh-core`.
- Standardized project licensing on Apache-2.0 and added public release and
  community documentation.

DSH 0.1.5 adaptation is in progress. It is not supported yet and has no
announced release date.
