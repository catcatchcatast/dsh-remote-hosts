# Support

Use [GitHub Issues](https://github.com/catcatchcatast/dsh-remote-hosts/issues)
for installation questions, compatibility reports, and reproducible bugs.
Include the DSH version, plugin versions, operating system, and redacted steps.

Send private logs, personal data, and security reports to
`catcatchcatast@gmail.com`. Never place credentials, authorization URLs, real
IP addresses, hostnames, device serial numbers, or session text in an Issue.

The current public line is DSH 0.1.2 Preview for `0.1.2-rc.1`. DSH 0.1.5 is
being adapted and is not supported yet.
